# Código de conduta

Este é um projeto pequeno e pessoal, então a regra é simples: **trate as outras pessoas com o mesmo respeito que você esperaria receber.**

## O que se espera

- Seja direto e honesto ao relatar um bug ou discordar de uma decisão, sem precisar ser hostil pra isso.
- Aceite que o autor pode discordar da sua sugestão ou fechar seu pull request sem aceitar — quando isso acontecer, [fazer um fork](README.md#contribuições) é sempre uma opção válida, não uma derrota.
- Mantenha issues e pull requests focados no projeto: bugs, ideias, código. Discussões político-partidárias fora do que já está declarado no [README](README.md#por-que-este-projeto-existe) não são o lugar.

## O que não é aceito

- Ataques pessoais, assédio, discurso de ódio ou qualquer conteúdo discriminatório (raça, gênero, orientação sexual, religião, nacionalidade, etc.).
- Spam, autopromoção sem relação com o projeto, ou uso das issues/pull requests pra divulgar outra coisa.
- Compartilhar dados pessoais de terceiros sem consentimento.

## O que acontece se isso for desrespeitado

Comentários, issues ou pull requests que violem isso podem ser editados, trancados ou removidos, e quem repetir o comportamento pode ser bloqueado do repositório. Como é um projeto de uma pessoa só, essa decisão é do autor, sem um processo formal de comitê.

## Como reportar um problema de conduta

Abra uma conversa privada com o autor através do e-mail vinculado ao perfil [github.com/murilobarbosa2002](https://github.com/murilobarbosa2002), ou pelo formulário de contato do GitHub, em vez de discutir publicamente numa issue.
