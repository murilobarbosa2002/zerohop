# v0.36.21 - Contatos com layout novo, experimento na captura de push-to-talk

## Melhorado

| Item | Descrição |
| --- | --- |
| Layout da tela de Contatos | Reorganizada em duas colunas (sala pessoal de um lado, contatos + adicionar contato do outro) em vez de cards empilhados um embaixo do outro |

## Experimento

| Item | Descrição |
| --- | --- |
| Captura de tecla do push-to-talk | Trocada a biblioteca usada por baixo dos panos (`node-global-key-listener` no lugar de `uiohook-napi`), depois de relatos de falha em capturar a tecla em alguns computadores Windows |

**Sobre o experimento:** não é uma correção garantida — é uma tentativa com uma biblioteca diferente depois de mais de uma falha registrada com a anterior. Se push-to-talk continuar sem detectar teclas nessa versão, a tela de Logs (categoria "Teclas de atalho") agora deve mostrar mais informação sobre o que está acontecendo do que mostrava antes.
