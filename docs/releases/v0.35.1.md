# v0.35.1 - Troca de fonte pixelada (legibilidade)

## Corrigido

| Item | Descrição |
| --- | --- |
| Letra "c" quase idêntica ao "d" na fonte pixelada | A fonte usada no visual retrô (Pixelify Sans, desde a v0.31.0) tinha um "c" fechado que ficava fácil de confundir com "d" em telas menores. Trocada por **Jersey 10**, outra fonte pixelada gratuita, mantendo o clima nostálgico mas com letras bem mais distintas |
| Ícone do app (barra de título/tela inicial) esquecido no reskin retrô | A florzinha nova (v0.32.1) só tinha sido aplicada no ícone da janela/barra de tarefas do Windows — o ícone dentro do próprio app (barra de título e tela inicial) continuou com o desenho antigo. Agora os dois usam a mesma florzinha |
| Link quebrado na tela de Changelog dentro do app | O texto de introdução do Changelog linkava pra pasta `docs/releases/` (não um arquivo específico), dando "404: Not Found" ao clicar. Removido — a própria tabela já é clicável por versão, o link era redundante |
