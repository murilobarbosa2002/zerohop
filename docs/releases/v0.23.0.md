# v0.23.0 - Captura experimental pra jogos com cursor sumindo/travando

## Adicionado

| Item | Descrição |
| --- | --- |
| Captura otimizada para jogos (experimental) | Novo interruptor em Configurações, desligado por padrão, que faz o app tentar usar a API `Windows.Graphics.Capture` do Windows em vez do método padrão de captura. Pode ajudar em jogos com cursor sumindo ou imagem travando/piscando ao compartilhar (relatado com Project Zomboid e Deadlock). Exige confirmação explícita antes de ligar e reiniciar o app pra fazer efeito. Essa API já causou travamento completo do PC em pelo menos um computador testado, então o risco é declarado com todas as letras antes de você optar por ativar |

## Documentação

Adicionamos uma seção honesta e detalhada no README e na documentação pública explicando os problemas conhecidos de compartilhar alguns jogos, o que já tentamos e não deu certo (forçar essa API pra todo mundo), o que decidimos não fazer e por quê (captura por injeção no processo do jogo, como Discord/OBS fazem. Risco de banimento em jogos com anti-cheat), e um convite aberto pra quem tiver uma solução real contribuir.

## Sem mudanças de comportamento existente

A opção vem desligada por padrão. Quem não mexer em nada continua exatamente como estava.
