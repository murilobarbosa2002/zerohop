# v0.36.32 - Aviso de senha faltando na sala pessoal, notificações clicáveis

## Novo

| Item | Descrição |
| --- | --- |
| Aviso de sala pessoal sem senha | Se "Abrir automaticamente" estiver ligado mas você ainda não definiu uma senha, um popup avisa toda vez que o app abre, com um botão pra ir direto definir a senha |
| Lembrete diário na aba de Notificações | Enquanto a sala pessoal continuar sem senha, uma notificação aparece uma vez por dia lembrando disso |
| Notificações clicáveis | Clicar numa notificação de "sala pessoal sem senha" leva direto pra Contatos com o campo de senha em foco; clicar numa notificação de atualização disponível leva direto pra tela de Atualizações |

## Melhorado

| Item | Descrição |
| --- | --- |
| Som de "conectado com sucesso" | O som ao criar/entrar numa sala (efeito de internet discada) ficou muito mais curto — o anterior chegava a durar dezenas de segundos |
| Sons de notificação | Convite que falhou/foi recusado e atualização disponível agora tocam um som ao chegar, junto com a nova notificação de sala pessoal sem senha |
