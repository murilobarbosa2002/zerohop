## Observação

Se ainda aparecer um processo chamado "ScreenShare" no Gerenciador de Tarefas ou no Alt+Tab, é uma instalação antiga (de antes do app se chamar ZeroHop) que ficou pra trás no Windows — o instalador novo não sabe que ela existe porque tecnicamente é outro programa aos olhos do Windows. É só desinstalar o "ScreenShare" antigo pelo painel "Aplicativos" do Windows; a instalação atual do ZeroHop não é afetada.
