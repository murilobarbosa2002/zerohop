# v0.15.0 - Desligar atualização automática e trava de versão na sala

## Adicionado

| Item | Descrição |
| --- | --- |
| Interruptor de atualização automática | Na aba "Atualização", é possível desligar a verificação/download automático (ligado por padrão). Útil pra quem escolheu de propósito ficar numa versão mais antiga. Sem isso, o app tentaria puxar a pessoa de volta pra versão mais nova sozinho. Verificação manual continua funcionando mesmo desligado |
| Trava de versão entre participantes | Duas pessoas com versões diferentes do app não conseguem mais entrar na mesma sala. A entrada é recusada automaticamente com uma mensagem explicando a diferença de versão |

## Sem mudanças de comportamento existente

Compartilhamento de tela, chat, senha de sala, aprovação manual de entrada e o comportamento automático de atualização (quando ligado) continuam funcionando exatamente como antes.
