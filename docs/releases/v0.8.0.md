# v0.8.0 - Interface e captura

## Adicionado

| Item                        | Descrição                                                                                                                |
| --------------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| Etiquetas de fonte          | Cada opção na lista de captura agora mostra se é "Tela toda" ou "Janela"                                                 |
| Áudio independente do vídeo | Seletor de áudio separado do de vídeo. Dá pra compartilhar a tela toda e escolher o áudio de só um aplicativo específico |
| Ícone próprio               | Novo ícone do app (monitor com seta de compartilhamento), substituindo o ícone padrão do Electron                        |

## Corrigido

| Item                            | Descrição                                                                                                     |
| ------------------------------- | ------------------------------------------------------------------------------------------------------------- |
| Miniaturas borradas             | Forçada decodificação síncrona das miniaturas de captura antes de exibir                                      |
| Janelas de notificação na lista | Filtradas notificações de sistema/antivírus (ex: pop-ups do ESET) que não fazem sentido como fonte de captura |
