# v0.12.0 - Layout da sala redesenhado

## Alterado

| Item                                      | Descrição                                                                                                                                                                                                                               |
| ----------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Layout da sala reorganizado em 3 colunas  | Coluna esquerda com código da sala e lista de participantes, palco central pro vídeo assistido/compartilhamento, coluna direita com o chat. Em vez de tudo empilhado numa única coluna                                                  |
| Compartilhar tela ficou mais simples      | Em vez do formulário de escolha de fonte sempre aberto, agora aparece um botão compacto "Compartilhar minha tela" que abre um painel só quando você clica; depois de compartilhar, vira uma barra de status compacta com botão de parar |
| Assistir alguém agora usa o palco central | O vídeo de quem você assiste aparece numa área dedicada e maior, em vez de espremido dentro do card da pessoa na lista de participantes                                                                                                 |
| Chat ganhou uma coluna própria            | Em vez de uma caixinha pequena no fim da página, o chat ocupa a altura inteira da coluna direita                                                                                                                                        |
| Painéis colapsáveis                       | É possível ocultar a coluna de participantes e a de chat pra ganhar mais espaço pro vídeo                                                                                                                                               |
| Janela um pouco maior por padrão          | O tamanho padrão e mínimo da janela aumentaram levemente pra acomodar o novo layout confortavelmente                                                                                                                                    |

## Sem mudanças de comportamento existente

Nenhuma mudança de protocolo, segurança ou funcionalidade. Compartilhamento de tela, áudio, chat, senha de sala, moderação e atualização automática continuam funcionando exatamente como antes. Esta versão é só reorganização visual.
