# v0.36.8 - Sons em todo o fluxo de compartilhar tela

## Adicionado

| Item | Descrição |
| --- | --- |
| Som ao clicar em "Compartilhar minha tela" pra abrir o fluxo | O botão inicial (antes de começar a compartilhar) não tinha nenhum som |
| Som ao escolher "Tela inteira" ou "Uma janela específica" | Cada opção tem seu próprio som, diferente da outra |
| Som ao clicar em "Cancelar" no meio da configuração de compartilhamento | Mesmo som em qualquer etapa desse cancelamento específico, diferente do cancelar usado em outras telas |
| Som ao selecionar uma tela/janela na lista de miniaturas | |
| Som ao mudar Resolução, FPS ou Áudio | Um som diferente pra cada um desses três campos |
| Som ao clicar em "Editar" numa transmissão já ativa | |
| Som ao salvar as alterações de uma transmissão em edição | Diferente do som de iniciar um compartilhamento novo |
