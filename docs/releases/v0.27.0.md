# v0.27.0 - Lista de fontes atualiza sozinha

## Adicionado

| Item | Descrição |
| --- | --- |
| Lista de telas/janelas atualiza sozinha | Enquanto o painel de escolher o que compartilhar está aberto (seja pra começar a compartilhar, seja editando com a call já rodando), a lista de janelas e telas se atualiza automaticamente a cada 2 segundos. Antes só atualizava manualmente, clicando em "Atualizar lista" (o botão continua existindo, pra quem quiser forçar uma atualização imediata) |
