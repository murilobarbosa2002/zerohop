# v0.36.28 - Toggles de auto-abertura, notificações com filtro/exclusão, corrige badge preso

## Novo

| Item | Descrição |
| --- | --- |
| Abrir sala pessoal automaticamente | Agora é configurável (ligado por padrão) na tela de Contatos |
| Habilitar sala automática | Agora é configurável (desligado por padrão) na tela de Contatos, antes da senha e da lista de convite |
| Indicador dentro da sala | A sala pessoal e a sala automática mostram uma etiqueta ("Sua sala pessoal"/"Sua sala automática") perto do código/senha, não só na aba lateral |
| Excluir uma notificação específica | Botão de excluir em cada notificação, com confirmação |
| Filtros de notificação | Dois filtros multi-select (tipo e categoria) na tela de Notificações |
| Som ao trocar de sala | Trocar de sala pela barra lateral agora tem som próprio |

## Corrigido

| Item | Descrição |
| --- | --- |
| Badge do sino preso | Marcar uma notificação como lida (ou todas, ou excluir) não atualizava o contador do sino na barra superior — cada tela tinha sua própria cópia do estado, sem sincronizar. Agora todas as telas recebem a atualização em tempo real |
| Sala escondida atrás de uma tela sobreposta | Trocar de sala pela barra lateral enquanto a tela de Notificações/Logs/Configurações estava aberta não mostrava a sala nova — agora a tela sobreposta fecha automaticamente ao trocar de sala |
| Sons faltando | "Marcar tudo como lido" e marcar uma notificação individual como lida agora têm som |
