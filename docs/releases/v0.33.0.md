# v0.33.0 - Apagar mensagens do chat, fontes maiores

## Adicionado

| Item | Descrição |
| --- | --- |
| Apagar mensagens do chat | Você pode apagar suas próprias mensagens a qualquer momento (some pra todo mundo na sala). Quem criou a sala também pode apagar a mensagem de qualquer participante, útil pra moderação |
| Paginação nas telas de Logs, Changelog e Versões | Essas listas só crescem com o tempo; agora ficam divididas em páginas em vez de uma lista enorme só |

## Mudado

| Item | Descrição |
| --- | --- |
| Fonte do nome/horário nas mensagens do chat aumentada | Estava difícil de ler com a fonte pixelada em tamanho pequeno |
| Fonte do horário na tela de Logs aumentada | Mesmo motivo — difícil de ler em tamanho pequeno |
| Notificação sobre a captura otimizada não aparece mais como aviso | Como essa captura virou o comportamento padrão do app (v0.31.0), a entrada no log deixou de ser um "aviso" chamativo e virou uma informação normal — ainda explica como desativar manualmente se precisar |
