# v0.4.0 - Salas com múltiplas pessoas

## Adicionado

| Item | Descrição |
| --- | --- |
| Sistema de salas | Qualquer pessoa cria ou entra numa sala com um código curto |
| Compartilhamento simultâneo | Várias pessoas podem compartilhar a tela ao mesmo tempo na mesma sala |
| Assistir sob demanda | Cada pessoa escolhe individualmente quem quer assistir, economizando banda de quem compartilha |
