# v0.17.2 - Notificação nativa de atualização

## Adicionado

| Item                                                          | Descrição                                                                                                                                                                                                                                   |
| ------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Notificação do sistema quando a atualização termina de baixar | Além do aviso dentro do app, agora aparece uma notificação nativa do Windows quando uma atualização termina de baixar. Útil pra saber mesmo com o app minimizado ou em segundo plano. Clicar na notificação traz a janela do app pra frente |

## Sem mudanças de comportamento existente

O download em si já acontecia dentro do app (sem precisar fechar/abrir); essa versão só adiciona o aviso nativo.
