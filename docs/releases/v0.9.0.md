# v0.9.0 - Reescrita da interface

## Alterado

| Item                                      | Descrição                                                                                                                                       |
| ----------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| Interface reescrita em React + TypeScript | Toda a tela do app foi reconstruída com componentes React tipados, mantendo a mesma aparência e funcionamento                                   |
| Build com Vite                            | Interface agora é compilada (antes rodava sem nenhuma etapa de build)                                                                           |
| Instalador gerado no CI                   | O instalador do Windows passa a ser compilado automaticamente numa máquina Windows real do GitHub, incluindo a nova etapa de build da interface |

## Sem mudanças pro usuário

Essa versão não adiciona nem remove nenhuma funcionalidade. Sala, compartilhamento de tela, áudio, controle de volume e atualização automática continuam funcionando exatamente como antes.
