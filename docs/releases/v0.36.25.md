# v0.36.25 - Convide contatos direto pra sala, sem aprovar entrada

## Adicionado

| Item | Descrição |
| --- | --- |
| Convidar contatos | Ao criar uma sala nova, marque contatos salvos pra convidar direto — sem código/senha, sem você precisar aprovar a entrada deles |

## Como funciona

Diferente de "Chamar" (você entrando na sala pessoal de alguém, que continua pedindo aprovação como sempre), convidar é você trazendo um contato pra uma sala que acabou de criar. A pessoa convidada entra automaticamente.

**Limitação:** só funciona se a pessoa convidada estiver com a sala pessoal dela aberta no momento — é a única forma do app alcançar ela sem depender de servidor nenhum. Se não estiver alcançável, o convite simplesmente não chega, sem erro.
