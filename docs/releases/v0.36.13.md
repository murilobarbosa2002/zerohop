# v0.36.13 - Erros de tecla de atalho visíveis, nome obrigatório, cor de texto ajustada de volta

## Adicionado

| Item                                                                     | Descrição                                                                                                                                                                      |
| ------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Aviso quando uma tecla de atalho não pode ser usada                      | Se a tecla escolhida pra mutar mic/áudio já estiver em uso por outro programa, agora aparece um aviso explicando o motivo, em vez de simplesmente não funcionar sem explicação |
| Som de erro ao tentar criar/entrar numa sala com campo obrigatório vazio |                                                                                                                                                                                |
| Botão "Copiar" na tela de Logs                                           | Copia o histórico inteiro como texto, pronto pra colar (Ctrl+V) numa conversa e mandar pra alguém ajudar a diagnosticar um problema                                            |

## Corrigido

| Item                                                                         | Descrição                                                             |
| ---------------------------------------------------------------------------- | --------------------------------------------------------------------- |
| Era possível criar ou entrar numa sala sem preencher o nome                  | Nome agora é obrigatório nos dois formulários                         |
| Texto de botões azuis (como "Assistir") estava muito claro/brilhante de novo | Voltou pro tom usado por várias versões (mais suave, sem branco puro) |

## Confirmado por teste real

Mutar mic e mutar áudio por tecla de atalho gravam e funcionam corretamente. Push-to-talk continua dependendo de uma biblioteca externa que parece não iniciar em alguns computadores — se isso acontecer, a categoria "Teclas de atalho" na tela de Logs mostra se a captura conseguiu iniciar ou não.
