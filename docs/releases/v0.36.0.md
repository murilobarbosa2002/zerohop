# v0.36.0 - Voz não parava mais, confirmação pra apagar mensagem, legibilidade

## Corrigido

| Item                                                                                                                   | Descrição                                                                                                                                                                                          |
| ---------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Ocultar a coluna de participantes cortava a voz de todo mundo                                                          | Era só pra ser visual, mas escondia o elemento de áudio junto — agora a voz continua tocando normalmente com a coluna oculta ou visível                                                            |
| Botão "Tela cheia" (de assistir alguém) aparecia flutuando por cima de outras telas (Atualizações, tela inicial, etc.) | Um problema de camadas (z-index): o botão furava a Configurações/Logs/Atualizações e ficava visível por cima delas. Corrigido garantindo que essas telas sempre ficam por cima do conteúdo da sala |
| Card de vídeo sozinho ficava esticado, com muito espaço preto                                                          | O grid agora limita a largura máxima de cada vídeo em vez de esticar pra ocupar a linha inteira sozinho                                                                                            |
| Textos pequenos demais e difíceis de ler                                                                               | Aumentado o tamanho das fontes usadas em quase toda a interface, e trocado o modo de suavização de fonte (estava desligado de propósito pelo visual retrô, mas ficou pesado demais de ler)         |
| Botões grandes demais em alguns diálogos                                                                               | Reduzido o preenchimento interno padrão dos botões da interface                                                                                                                                    |

## Adicionado

| Item                                                     | Descrição                                                                                                                                                             |
| -------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Confirmação ao apagar mensagem do chat                   | Agora pergunta antes de apagar de verdade, pra evitar clique acidental                                                                                                |
| Sons de apagar mensagem                                  | Um som toca pra quem apaga (a própria mensagem ou, sendo dono da sala, a de qualquer um); um som diferente toca pra quem só vê a mensagem sumir (não foi quem apagou) |
| Sons ao clicar em "Criar sala nova" e "Entrar numa sala" | Cada botão tem um som diferente                                                                                                                                       |
