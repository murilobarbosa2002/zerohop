# v0.16.0 - Tela de Atualizações reformulada

## Alterado

| Item                                | Descrição                                                                                                                                                                                      |
| ----------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Atualizações vira tela cheia        | Em vez de um pop-up pequeno e apertado, "Atualizações" agora abre como uma página cheia, com navegação lateral entre Atualização/Changelog/Versões e bem mais espaço                           |
| Changelog com formatação de verdade | O histórico de versões deixa de aparecer como texto cru e passa a ser renderizado com título, texto e tabela. Cada versão é um link clicável que abre o detalhe daquela versão sem sair do app |

## Sem mudanças de comportamento existente

Verificar atualizações, o interruptor de atualização automática, a lista de versões e a trava de versão entre participantes continuam funcionando exatamente como antes. Essa versão é só um redesenho visual dessa tela.
