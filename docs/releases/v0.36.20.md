# v0.36.20 - Contatos: chame um amigo sem trocar código toda vez

## Adicionado

| Item | Descrição |
| --- | --- |
| Tela de Contatos | Nova opção na tela inicial. Mostra sua "sala pessoal" (um ID e uma senha só seus, sempre os mesmos) e a lista de contatos salvos |
| Sala pessoal | Escolha uma senha e clique em "Abrir minha sala pessoal" — funciona como qualquer sala, só que o código é sempre o seu ID, nunca muda |
| Adicionar contato | Peça o ID e a senha da sala pessoal de um amigo (ele vê os dois na própria tela de Contatos) e salve com um apelido |
| Chamar um contato | Um clique — sem precisar digitar código ou senha de novo. A pessoa ainda precisa aprovar sua entrada, igual em qualquer sala |
| Sons próprios | Abrir Contatos, chamar, salvar e remover um contato, e abrir a sala pessoal — cada ação com seu som |

## Observação

O ID e a senha da sua sala pessoal ficam salvos só no seu computador, e a lista de contatos fica num arquivo próprio (`contacts.json`, junto dos outros arquivos do app) — nada disso passa por servidor nenhum.
