# v0.26.0 - Repositório novo: zerohop

## Alterado

| Item | Descrição |
| --- | --- |
| Repositório do GitHub recriado como `zerohop` | O repositório antigo (`electron-screen-share`) foi apagado e o código republicado em [`murilobarbosa2002/zerohop`](https://github.com/murilobarbosa2002/zerohop), com o histórico completo de commits preservado. O pacote npm também passou a se chamar `zerohop` (era `zero-hop`), o que muda a pasta de configurações no Windows para `%APPDATA%\zerohop\settings.json` |
| Ícones da interface extraídos para componentes próprios | SVGs que antes eram funções internas de outros componentes agora vivem em `components/icons/`, um arquivo por ícone |

## Sem mudanças de comportamento existente

Nenhuma funcionalidade muda para quem já usa o app. Quem tinha a versão anterior instalada recebe a atualização normalmente pelo autoupdate; a pasta de configurações antiga (`%APPDATA%\zero-hop\`) fica órfã no disco (pode ser apagada manualmente), já que o app passa a usar a nova a partir desta versão.
