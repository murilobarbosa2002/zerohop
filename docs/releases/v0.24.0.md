# v0.24.0 - Novo nome: ZeroHop

## Adicionado

| Item | Descrição |
| --- | --- |
| App renomeado de ScreenShare pra ZeroHop | O escopo do projeto cresceu além de só compartilhar tela (agora tem chat de voz, chat de texto, logs auditáveis), então o nome mudou pra refletir isso. "Zero saltos": a conexão é sempre direta entre os dois PCs, sem servidor no meio |

## Corrigido

| Item | Descrição |
| --- | --- |
| Arquivo de configurações não existia se nada fosse mudado | O `settings.json` só era criado quando você mexia em algum interruptor. Se você nunca tinha mexido em nada, o arquivo simplesmente não existia, o que quebrava a orientação de "editar esse arquivo se o app não abrir mais". Agora o arquivo já é criado com os valores padrão na primeira vez que o app abre |

## Sem mudanças de comportamento existente

Nenhuma funcionalidade muda. O identificador do app no Windows também muda junto com o nome (`com.zerohop.app`), então instalações anteriores viram "outro app" pro Windows, o que é esperado numa troca de nome.
