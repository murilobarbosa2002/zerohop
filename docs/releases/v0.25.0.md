# v0.25.0 - Nitidez do compartilhamento e edição durante a call

## Corrigido

| Item                                                | Descrição                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| --------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Vídeo compartilhado saindo borrado pra quem assiste | A captura de tela não avisava o WebRTC que o conteúdo era tela/texto (não câmera), então o encoder priorizava suavidade de movimento em vez de nitidez. Agora a track de vídeo é marcada com `contentHint = 'detail'` e a conexão prefere manter a resolução em vez de reduzi-la sob pressão de rede (`degradationPreference: 'maintain-resolution'`). A captura também passou a travar exatamente na resolução escolhida, em vez de aceitar qualquer coisa numa faixa ampla |

## Adicionado

| Item                                              | Descrição                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| ------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Editar o compartilhamento com a call já rolando   | Agora dá pra trocar resolução, FPS, áudio ou a fonte (tela/janela) sem precisar parar e começar de novo o compartilhamento. Um novo botão "Editar" aparece ao lado de "Parar de compartilhar"; a troca acontece sem interromper quem está assistindo (a mesma técnica já usada pra trocar de microfone no chat de voz, sem reconectar nada). Trocar entre "com áudio" e "sem áudio" no meio da call ainda não é suportado, isso continua exigindo parar e recomeçar |
| `ErrorBoundary` na interface                      | Um erro inesperado de renderização agora mostra uma tela de fallback com botão de recarregar, em vez de deixar a interface inteira em branco. O erro também vira uma entrada auditável na tela de Logs                                                                                                                                                                                                                                                              |
| Atributos de acessibilidade básicos               | Botões só com ícone (barra de título, controles de voz) ganharam `aria-label`, e ícones puramente decorativos ganharam `aria-hidden`                                                                                                                                                                                                                                                                                                                                |
| Suíte de testes end-to-end versionada (`e2e/`)    | Os testes que antes eram scripts descartáveis viraram uma suíte permanente no repositório (`npm run test:e2e`), cobrindo criação/entrada em sala, compartilhamento (incluindo editar com a call rodando), chat de voz e configurações/logs                                                                                                                                                                                                                          |
| CI no GitHub Actions (`.github/workflows/ci.yml`) | Todo push na `main` e todo pull request agora roda checagem de tipos, build, lint de Markdown e a suíte de testes end-to-end automaticamente                                                                                                                                                                                                                                                                                                                        |
| `CONTRIBUTING.md`                                 | Novo guia na raiz do repositório com como rodar o projeto localmente, rodar os testes e as convenções de código pra quem for mandar um pull request                                                                                                                                                                                                                                                                                                                 |
