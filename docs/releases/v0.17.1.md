# v0.17.1 - Correções no seletor de fonte e áudio

## Corrigido

| Item | Descrição |
| --- | --- |
| Campo de áudio cortando o texto | O seletor de áudio tinha a mesma largura estreita dos campos de resolução/FPS, cortando opções como "Junto com o que eu compartilhar". Agora tem uma largura própria, maior |
| Opções de áudio com texto confuso | Os textos das opções de áudio foram encurtados e simplificados |
| Janelas duplicadas na lista (ex: WhatsApp aparecendo duas vezes) | Alguns apps (como o WhatsApp Desktop) expõem mais de uma janela com nome e miniatura idênticos. Agora essas duplicatas são filtradas automaticamente, mantendo só uma entrada por janela |

## Sem mudanças de comportamento existente

O restante do fluxo de compartilhamento continua igual.
