# v0.36.50 - Responder, reagir e editar mensagens no chat

## Adicionado

| Item | Descrição |
| --- | --- |
| Responder mensagem | Botão de responder (↩) em cada mensagem mostra a citação acima da resposta, com um trecho da mensagem original |
| Reações com emoji | Botão de reagir (😀+) abre um seletor rápido de emojis; cada reação mostra a contagem e quem reagiu fica destacado |
| Editar mensagem própria | Botão de editar (✎) só aparece nas suas próprias mensagens; a mensagem editada ganha a marca "(editado)" pra todo mundo na sala |

## Alterado

| Item | Descrição |
| --- | --- |
| Cabeçalho da mensagem | Ganhou os botões de responder/editar/apagar lado a lado |
