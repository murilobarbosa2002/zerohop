# v0.11.0 - Senha obrigatória e fluxo de criar/entrar separado

## Alterado

| Item | Descrição |
| --- | --- |
| Senha de sala obrigatória | Toda sala agora nasce protegida. Não é mais possível criar uma sala sem definir uma senha (mínimo de 4 caracteres) |
| Tela inicial dividida em duas | Em vez de um único formulário misturando os campos de criar e entrar, a tela inicial agora pergunta primeiro o que você quer fazer, levando a um formulário dedicado só com os campos daquela ação |
| Correção: senha errada agora mostra erro de verdade | Antes, tentar entrar com a senha errada abria a tela da sala vazia, sem explicar o motivo. Agora o app espera a confirmação da senha antes de prosseguir e mostra uma mensagem de erro, mantendo você no formulário de entrar |

## Sem mudanças de comportamento existente

Compartilhamento de tela, áudio, chat, moderação de sala e atualização automática continuam funcionando exatamente como antes desta versão.
