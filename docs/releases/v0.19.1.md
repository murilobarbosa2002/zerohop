# v0.19.1 - Aviso sobre janela ficando preta ao trocar de foco

## Adicionado

| Item                                        | Descrição                                                                                                                                                                                                                                                                                                                                                     |
| ------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Aviso na escolha de "Uma janela específica" | Compartilhar uma janela específica (não a tela inteira) pode ficar preta quando você troca de janela (Alt+Tab) e ela sai de primeiro plano. É uma limitação do Windows com alguns programas, não um bug do app. Um aviso agora explica isso na hora de escolher e recomenda usar "Tela inteira" se você for alternar entre janelas durante o compartilhamento |

## Sem mudanças de comportamento existente

Isso é só um aviso. Nenhum comportamento de captura mudou.
