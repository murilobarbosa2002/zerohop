# v0.29.0 - Áudio isolado por aplicativo (experimental)

## Adicionado

| Item | Descrição |
| --- | --- |
| Áudio isolado por aplicativo ao compartilhar janela (experimental) | Novo interruptor em Configurações, desligado por padrão. Corrige de verdade uma limitação antiga: escolher "áudio de só um app específico" nunca isolava o áudio de fato, sempre capturava o áudio de saída do sistema inteiro (limitação do Chromium, não bug deste app). A correção usa uma biblioteca nativa (WASAPI Process Loopback do Windows) pra capturar o áudio só do processo escolhido. Como depende de código nativo de terceiros ainda pouco testado, vem desligada e pede confirmação explícita pra ativar — veja [TROUBLESHOOTING.md](../../TROUBLESHOOTING.md) pra detalhes |

## Corrigido

| Item | Descrição |
| --- | --- |
| Texto do seletor de áudio deixando de prometer algo que não entregava | O aviso "áudio independente do vídeo" agora deixa explícito que, sem a opção experimental ativada, o áudio de "app específico" é na prática o áudio do sistema inteiro |
