# v0.10.0 - Senha de sala, moderação, chat e documentação pública

## Adicionado

| Item | Descrição |
| --- | --- |
| Senha opcional de sala | Ao criar uma sala, é possível definir uma senha. Quem for entrar precisa digitar exatamente a mesma senha, além do código |
| Remover participante | Quem criou a sala pode remover qualquer outro participante dela; a conexão é encerrada dos dois lados e a pessoa fica impedida de reconectar sozinha na mesma sessão |
| Chat de texto na sala | Nova aba de mensagens dentro da sala. Nenhuma mensagem é salva em disco, servidor ou qualquer outro lugar — existem só na memória de cada participante e somem ao sair da sala |
| Reconexão automática | Se a conexão direta com alguém cair ou demorar demais pra abrir, o app tenta reconectar sozinho algumas vezes, sempre de forma direta (nunca via relay) |
| Documentação pública | Novo site de documentação, cobrindo uso, segurança/privacidade, arquitetura e perguntas frequentes, publicado gratuitamente em `murilobarbosa2002.github.io/electron-screen-share` |

## Alterado

| Item | Descrição |
| --- | --- |
| Validação de mensagens da sala | Toda mensagem trocada entre participantes agora passa por uma validação de formato antes de ser processada; uma mensagem fora do padrão esperado é descartada |
| README | Reescrito com foco em transparência: explica claramente o que o app faz, como funciona, o que garante em termos de privacidade e como contribuir ou criar um fork |
| Licença | Projeto formalmente licenciado sob MIT |

## Sem mudanças de comportamento existente

Compartilhamento de tela, áudio, controle de volume e atualização automática continuam funcionando exatamente como antes desta versão.
